# French Reader gesture guide

## English

👆 Tap · ✋ Long-press · ↔️ Drag / select · ↕️ Vertical swipe / scroll · ⬅️➡️ Horizontal swipe

### Reading

- 👆 French word → dictionary
- ✋ Word → select; drag handles to extend
- 👆 Selection → toolbar: highlight, define/save, more
- ⬅️➡️ Paged mode → swipe horizontally or vertically to turn pages
- 👆 Blank page edge → turn page

### Watch

- ↕️ Transcript → browse subtitles
- 👆 French subtitle word → dictionary
- ↔️ Hold and drag across words → phrase dictionary
- 👆 Translation → seek sentence; failed translation → retry
- ✋ Available translation → edit correction

### Vocabulary and flashcards

- 👆 Vocabulary row → preview flashcard
- ✋ Vocabulary row → start selection for bulk actions
- 👆 Additional rows → toggle selection
- 👆 Hidden flashcard → reveal meaning
- 👆 Vocabulary preview → tap again to flip back

### Library

- 👆 Text → open
- ✋ Text → start selection for bulk actions
- 👆 Selection mode: other texts → toggle selection
- ↕️ List → browse texts

### Home

- 👆 Recent text → resume reading
- ↕️ Home → browse screen

### Shadowing and pronunciation

- ✋ Reading/video microphone → record; release → finish
- ✋ Review pronunciation practice, when enabled → same hold/release gesture

### Dictionary and selectable French text

- 👆 Tappable French words, including dictionary/flashcard examples → dictionary
- ✋ Where enabled → start text selection
- ↔️ Selection handles → select text

### Statistics

- ↕️ Statistics → browse statistics and charts

## Français

👆 Toucher · ✋ Appui long · ↔️ Glisser / sélectionner · ↕️ Balayage vertical / défilement · ⬅️➡️ Balayage horizontal

### Lecture

- 👆 Mot français → dictionnaire
- ✋ Mot → sélectionner ; étirer avec les poignées
- 👆 Sélection → barre : surligner, définir/enregistrer, plus
- ⬅️➡️ Mode paginé → balayer horizontalement ou verticalement pour tourner les pages
- 👆 Bord vide de la page → tourner la page

### Vidéos

- ↕️ Transcription → parcourir les sous-titres
- 👆 Mot des sous-titres français → dictionnaire
- ↔️ Appui long et glisser sur des mots → dictionnaire de l’expression
- 👆 Traduction → aller à la phrase ; échec → réessayer
- ✋ Traduction disponible → modifier la correction

### Vocabulaire et fiches

- 👆 Ligne de vocabulaire → aperçu de la fiche
- ✋ Ligne de vocabulaire → commencer une sélection pour actions groupées
- 👆 Autres lignes → sélectionner/désélectionner
- 👆 Fiche masquée → révéler le sens
- 👆 Aperçu du vocabulaire → retoucher pour revenir au recto

### Bibliothèque

- 👆 Texte → ouvrir
- ✋ Texte → commencer une sélection pour actions groupées
- 👆 Mode sélection : autres textes → sélectionner/désélectionner
- ↕️ Liste → parcourir les textes

### Accueil

- 👆 Texte récent → reprendre la lecture
- ↕️ Accueil → parcourir l’écran

### Répétition et prononciation

- ✋ Microphone en lecture/vidéo → enregistrer ; relâcher → terminer
- ✋ Prononciation en révision, si activée → même maintien/relâchement

### Dictionnaire et texte français sélectionnable

- 👆 Mots français interactifs, exemples du dictionnaire/des fiches → dictionnaire
- ✋ Si activée → commencer la sélection du texte
- ↔️ Poignées de sélection → sélectionner le texte

### Statistiques

- ↕️ Statistiques → parcourir les statistiques et graphiques

## فارسی

👆 ضربه · ✋ لمس طولانی · ↔️ کشیدن / انتخاب · ↕️ کشیدن عمودی / پیمایش · ⬅️➡️ کشیدن افقی

### مطالعه

- 👆 واژهٔ فرانسوی ← دیکشنری
- ✋ واژه ← انتخاب؛ دستگیره‌ها را برای گسترش بکشید
- 👆 انتخاب ← نوار ابزار: هایلایت، معنی/ذخیره، بیشتر
- ⬅️➡️ حالت صفحه‌ای ← کشیدن افقی یا عمودی برای ورق زدن
- 👆 لبهٔ خالی صفحه ← ورق زدن

### تماشای ویدئو

- ↕️ متن زیرنویس ← پیمایش زیرنویس‌ها
- 👆 واژهٔ زیرنویس فرانسوی ← دیکشنری
- ↔️ نگه داشتن و کشیدن روی واژه‌ها ← دیکشنری عبارت
- 👆 خط ترجمه ← رفتن به جمله؛ ترجمهٔ ناموفق ← تلاش دوباره
- ✋ ترجمهٔ موجود ← ویرایش اصلاحیه

### واژگان و فلش‌کارت‌ها

- 👆 ردیف واژه ← پیش‌نمایش فلش‌کارت
- ✋ ردیف واژه ← شروع انتخاب برای کارهای گروهی
- 👆 ردیف‌های دیگر ← انتخاب/لغو انتخاب
- 👆 فلش‌کارت پنهان ← نمایش معنی
- 👆 پیش‌نمایش واژگان ← ضربهٔ دوباره برای برگشتن به روی کارت

### کتابخانه

- 👆 متن ← بازکردن
- ✋ متن ← شروع انتخاب برای کارهای گروهی
- 👆 حالت انتخاب: متن‌های دیگر ← انتخاب/لغو انتخاب
- ↕️ فهرست ← پیمایش متن‌ها

### خانه

- 👆 متن اخیر ← ادامهٔ مطالعه
- ↕️ خانه ← پیمایش صفحه

### تمرین تکرار و تلفظ

- ✋ میکروفون مطالعه/ویدئو را نگه دارید؛ رها کنید تا تمام شود
- ✋ تمرین تلفظ مرور، اگر فعال باشد ← همین نگه‌داشتن/رهاکردن

### دیکشنری و متن فرانسوی قابل انتخاب

- 👆 واژه‌های فرانسوی قابل لمس، ازجمله مثال‌های دیکشنری/فلش‌کارت ← دیکشنری
- ✋ هرجا فعال باشد ← شروع انتخاب متن
- ↔️ دستگیره‌های انتخاب ← انتخاب متن

### آمار

- ↕️ آمار ← پیمایش آمار و نمودارها
