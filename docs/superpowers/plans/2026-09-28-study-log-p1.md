# Study Log P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add P1 study-time logging, source management, correct Week/Month aggregates, charts, navigation, localization, backup coverage, and migration/DAO tests without any P2/P3 schema or UI.

**Architecture:** Room owns sources and sessions and exposes date-range flows; `StudyLogAggregates.kt` is the sole pure aggregation layer. One `AndroidViewModel` combines database flows and preferences into screen-ready state, while focused Compose files render home, entry, sources, and charts and reuse a new Canvas stacked chart.

**Tech Stack:** Kotlin, Room, coroutines/Flow, AndroidViewModel, Jetpack Compose Material3 1.2.1, JUnit4, AndroidX instrumented tests.

**Spec:** User-supplied “Study Log & Exam Tracker — design plan”, restricted to Phase P1.

## Global Constraints

- Implement Phase P1 only: no `practice_score`, `exam_goal`, weekly targets, All-time/cumulative charts, or scores UI.
- Store dates as local epoch days and durations as integer minutes.
- Store `StudySkill` and `SourceKind` as stable string codes, never ordinals.
- Use only Material3 APIs available in 1.2.1.
- Every `study_log_*` string key must exist in default, French, and Persian resources; Compose must contain no hardcoded Persian.
- Do not mix reader `activity_log` time into study-log totals.
- Do not commit.

## Review Focus

- Editing a session must exclude its prior row from the day-total warning calculation.
- Archived sources remain visible in history/statistics but are omitted from the entry picker.
- Week and Month charts include future zero buckets while averages use elapsed days only.
- Case-only duplicate source names fail through the `COLLATE NOCASE` unique index and surface as a form error.
- Source deletion remains unavailable for used sources and is also protected by `ON DELETE RESTRICT`.
