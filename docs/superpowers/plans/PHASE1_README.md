# فاز ۱: اپ واقعی (نه دیگر آزمون تک‌صفحه‌ای)

پروژه از یک صفحهٔ آزمایشی به یک اپ دو-صفحه‌ای تبدیل شد:

- **صفحهٔ متن‌ها**: لیست متن‌های ذخیره‌شده + دکمهٔ `+` برای افزودن متن جدید
  (فعلاً فقط با چسباندن متن؛ ورود فایل TXT/MD در فاز ۲ اضافه می‌شود).
- **صفحهٔ مطالعه**: متن به‌صورت جمله‌به‌جمله نمایش داده می‌شود، صدا تولید و
  پخش می‌شود، و **پس‌زمینهٔ جملهٔ در حال پخش** بر اساس زمان واقعی پخش عوض
  می‌شود (نه هایلایت کلمه‌به‌کلمه — دقیقاً همان چیزی که طرح اصلی خواسته
  بود).

## تغییرات فنی مهم

- به‌جای `boundary="WordBoundary"` (که فقط برای آزمون فنی استفاده شد)، حالا
  از `boundary="SentenceBoundary"` در `tts_engine.py` استفاده می‌شود —
  خود edge-tts جمله‌بندی فرانسوی (مخفف‌ها، آپاستروف، گیومه) را انجام
  می‌دهد، پس نیازی به بازنویسی این منطق در اپ نبود.
- متن به «قطعه»‌های حدود ۷۰۰ کاراکتری (براساس پاراگراف) تقسیم می‌شود؛ هر
  قطعه جدا تولید و کش می‌شود (کلید کش = متن+صدا+سرعت). قطعهٔ اول را که
  آماده شد پخش شروع می‌شود و بقیه در پس‌زمینه آماده می‌شوند.
- موقعیت مطالعه (کدام قطعه + کدام میلی‌ثانیه) هر چند ثانیه و هنگام خروج از
  صفحه در پایگاه دادهٔ محلی (Room) ذخیره می‌شود.
- کتابخانه‌های جدید اضافه شدند: Room (پایگاه داده)، Navigation Compose،
  KSP (برای تولید کد Room). **حتماً یک‌بار Gradle Sync بزنید** چون
  `app/build.gradle` تغییر کرده.

## چک‌لیست تست (معیارهای پذیرش ۱ تا ۳ طرح اصلی)

1. اپ را باز کنید → صفحهٔ «متن‌ها» خالی است → دکمهٔ `+` را بزنید.
2. یک متن نسبتاً بلند فرانسوی (چند پاراگراف، حداقل ۲-۳ صفحه اگر دارید)
   بچسبانید و «ذخیره و باز کردن» را بزنید.
3. صبر کنید بخش اول آماده شود (اسپینر تمام‌صفحه) → پخش خودکار شروع نمی‌شود؛
   دکمهٔ پخش ▶ وسط نوار پایین را بزنید.
4. بررسی کنید: آیا پس‌زمینهٔ جملهٔ در حال پخش عوض می‌شود و با صدا هماهنگ
   است؟
5. روی یک جملهٔ دیگر (جلوتر یا عقب‌تر) تپ کنید — آیا پخش از همان‌جا ادامه
   پیدا می‌کند؟
6. دکمه‌های ⏮ (جملهٔ قبل)، ⏭ (جملهٔ بعد)، ۱۰ ثانیه جلو/عقب، و منوی سرعت
   (0.75x تا 1.5x) را امتحان کنید.
7. وسط پخش، از اپ خارج شوید (دکمهٔ Back سیستم یا Home)، دوباره اپ را باز
   کنید و همان متن را باز کنید — آیا دقیقاً از همان‌جا ادامه می‌دهد؟
8. اپ را کامل ببندید (از Recent Apps سوایپ کنید) و دوباره باز کنید — آیا
   موقعیت هنوز درست است؟ (این چون هر ۳ ثانیه در پایگاه داده ذخیره می‌شود.)
9. یک متن با پاراگراف‌های زیاد امتحان کنید تا چند «قطعه» ساخته شود — آیا
   انتقال بین قطعه‌ها (وقتی صدای یک قطعه تمام می‌شود) بدون وقفهٔ عجیب اتفاق
   می‌افتد؟

## چیزهایی که هنوز نیستند (فازهای بعدی)

- ورود فایل TXT/MD واقعی (فعلاً فقط چسباندن متن)
- دیکشنری (تپ روی کلمه) و ذخیرهٔ لغت
- تنظیمات فونت/حالت شب
- پخش در پس‌زمینه با صفحهٔ خاموش و کنترل از اعلان (فعلاً باید اپ باز باشد)
- خروجی/ورودی JSON پشتیبان

اگر چیزی کرش کرد یا رفتار عجیبی داشت، لاگ Logcat (فیلتر `AndroidRuntime`)
را برایم بفرستید.
